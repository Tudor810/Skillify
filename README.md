🧠 Skillify — Learn Smarter with AI

Skillify is an intelligent learning platform that helps users master any topic through interactive, conversational learning.
It uses OpenAI’s language model (LLM) to explain concepts, quiz you, and adapt to your learning style — all through a simple web interface.

💬 AI-Powered Learning – Personalized, conversational guidance powered by OpenAI.

🧩 Topic-Based Lessons – Learn anything: math, science, coding, history, or languages.

🧠 Adaptive Quizzing – The AI asks questions based on your progress and understanding.

⚡ Fast & Responsive – Built with modern web technologies for smooth performance.

🎨 Clean UI – A distraction-free learning interface that keeps you focused.

🛠️ Tech Stack

Frontend: React
Backend: Node.js / Express
DataBase: MongoDb
AI Engine: OpenAI API (GPT model)

Version Control: Git & GitHub

📦 Installation

Clone the repository

git clone https://github.com/Tudor810/Skillify.git
cd Skillify

Install dependencies

1. cd frontend
2. npm install
3. cd backend
4. npm install

Add your OpenAI API key
Create a .env file in the project root:

OPENAI_API_KEY=your_api_key_here

Run the app

npm start

Visit your app at
👉 http://localhost:3000

🧩 Usage

Enter a topic or question to start learning.
Chat with the AI tutor to explore concepts step by step.
Use the quiz mode to test your knowledge.
